Next build 1

The Cockpit: useful and dangerous in the same sentence

  • Boots read-only. Write mode is one click, and the header turns red.
  • An allowlist, not a denylist. A refused command is the worst case.
  • Pinned to the brain folder. Anything that resolves outside it is refused.
  • Never reads .env. Every command is logged before it runs.
Honest limitA speed bump, not a wall. Git is why Class 8 came first.

The offline checker passes forty-five refusals and twenty allowed commands. It has not run inside a live dashboard.

Say the word out loud at each step.

Step 1 · Think

The best prompt is a decision you made before you opened the AI.

  1. Who visits? A customer with a quick question.
  2. What do they need? Hours, prices, how to reach me.
  3. What is the smallest thing that solves it? Three pages and a bot that answers from facts I wrote.

Scope: Home, Chat, About. One config file. No database.

Step 2 · Prompt

The master prompt, and read what it writes

Paste into Claude Code in an empty folder. The full text is in 03-MASTER-PROMPT.txt in the kit.

  • Plain HTML, CSS and JavaScript. No framework.
  • Everything personal lives in config.json.
  • The chatbot runs as a Cloudflare Pages Function. The key never reaches the browser.
  • The bot answers only from your list, under 60 words, and says it is an AI.

Reviewing the AI's code is the skill. Ask: what would you change before running this?

Steps 3 to 5

Make it yours, save it, name it

  • Edit only config.json: name, tagline, about, five to eight real facts.
  • Ask the bot something it knows, then something it does not. It should say it does not know.
git init -b main git add . git status # .dev.vars is NOT listed git commit -m "feat: first version of my business card" git tag v0.1.0

A commit is a save point. A tag is a name for a release. Secrets never go in git.

Steps 6 and 7

Deploy, then try to break it

npx wrangler login npx wrangler pages deploy . --project-name my-business-card npx wrangler pages secret put GEMINI_API_KEY --project-name my-business-card
  • The key lives in Cloudflare, not in your code and not in git.
  • Open your pages.dev address on your phone.
  • Pair up. Try to break your partner's bot.

Free Gemini quota is small. If you see 429, it is the free tier doing what it said.

Run one prompt. Look. Commit. Then the next.

Every word comes from config.json. Do not let the AI invent clients, numbers or testimonials.

Step 2 of the kit

A hero video that does not look broken

  • Short: five to ten seconds, looped.
  • Small: under 5 MB.
  • Autoplay, muted, loop, playsinline, with a poster image.
  • A dark layer so the headline passes contrast.
  • Reduced-motion setting: poster only.
Check itZoom in. Edges breaking up means the video is smaller than the space it fills. Fix the file, not the prompt.
