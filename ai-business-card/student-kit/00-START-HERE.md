# Build and Ship Your Own AI Business Card (in 30 minutes)

Today you will build a small website with a chatbot that answers questions about **your** business, put it on the internet, and keep a clean history of every change.

**You will leave with:**
- A live link you can send to a customer (`https://your-name.pages.dev`)
- A chatbot that knows your services, prices and hours
- Your own logo, name and About page
- A git history with tagged versions you can roll back to

## The 7 steps
**Think → Prompt → Build → Git → Version → Deploy → Execute**

| # | Step | What happens | Time |
|---|---|---|---|
| 1 | Think | Decide who visits and what they need | 5 min |
| 2 | Prompt | Give the AI one clear prompt | 7 min |
| 3 | Build | Make it yours: edit one config file | 5 min |
| 4 | Git | Save your work as a commit | 3 min |
| 5 | Version | Tag it `v0.1.0` | 2 min |
| 6 | Deploy | Publish on Cloudflare Pages | 5 min |
| 7 | Execute | Open it on your phone and chat | 3 min |

## If you get stuck
Copy the `starter-app/` folder, rename it, and keep going from Step 3. A working copy beats a broken build.
