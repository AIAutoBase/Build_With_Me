# Lesson 06: Build and test a small local workshop landing page — quiz

## 1. Which is testable?

A. Make it impressive
B. The main button reaches the practice form
C. Use a trendy design
D. Promise more registrations

## 2. What does selecting Astra provide?

A. Automatic browser access
B. Permission to publish
C. Model reasoning within available tools and permissions
D. A real mailing list

## 3. What should the practice confirmation say?

A. You are registered
B. Payment received
C. Your seat is guaranteed
D. No information was sent or saved

## 4. Browser tools are missing. What should the report say?

A. Source inspected; browser behavior unverified
B. All browser checks passed
C. No page can be built
D. The model tested it mentally

## 5. The main link fails. What comes next?

A. Replace the project
B. Inspect its target and repeat the check
C. Publish immediately
D. Add several packages

## Answer key

1. **B — The main button reaches the practice form**. It names observable behavior.

2. **C — Model reasoning within available tools and permissions**. Model selection does not create tools or grant access.

3. **D — No information was sent or saved**. The message must match the demonstration behavior.

4. **A — Source inspected; browser behavior unverified**. Source inspection differs from observed browser behavior.

5. **B — Inspect its target and repeat the check**. A focused correction preserves working behavior.
