# Practice workspace instructions

This is a fictional classroom exercise. Keep work inside this folder.

- Read brief.md before changing files.
- Preserve known facts. Identify missing information instead of inventing it.
- Use standard HTML, CSS, JavaScript, and the Python standard library.
- Keep the page accessible by keyboard and usable on a narrow screen.
- Do not send messages, publish pages, connect accounts, or collect personal data.
- For the Python lab, run `python -m unittest discover -s debugging -v`.
- Report what changed, actual checks, and any remaining limitation.
- The debugging starter intentionally contains errors. Fix the implementation rather than weakening the tests.
