# Lesson 03: Files, projects, AGENTS.md, and useful context — quiz

## 1. Which file should govern the meeting day?

A. The most entertaining example
B. The approved factual brief
C. Whichever file is longest
D. The oldest draft

## 2. What belongs in AGENTS.md?

A. Every raw data row
B. A one-time headline experiment
C. Durable working rules and relevant verification requirements
D. Unrelated copied web pages

## 3. Does AGENTS.md grant operating-system file access?

A. Yes, for all subfolders
B. Yes, if Astra is selected
C. Only if written in Markdown
D. No, instructions and access controls are distinct

## 4. What should you check when instructions appear stale?

A. Active directory, applicable instruction sources, and a fresh run
B. Only the output font
C. The length of the prompt
D. Whether the model sounds confident

## 5. What is strongest evidence that a saved output is correct?

A. The filename sounds appropriate
B. The agent reports success
C. Inspecting the actual file against the source and criteria
D. The output folder already exists

## Answer key

1. **B — The approved factual brief**. Explicit source roles prevent style material from overriding approved facts.

2. **C — Durable working rules and relevant verification requirements**. AGENTS.md is useful for persistent working agreements, with references kept separate.

3. **D — No, instructions and access controls are distinct**. Environment permissions control available actions; guidance describes expected behavior.

4. **A — Active directory, applicable instruction sources, and a fresh run**. Discovery depends on scope and run startup, so inspect actual instruction sources.

5. **C — Inspecting the actual file against the source and criteria**. A completion statement cannot substitute for checking the resulting artifact.
