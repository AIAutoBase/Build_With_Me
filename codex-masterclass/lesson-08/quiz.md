# Lesson 08: Skills, plugins, MCP, and connected tools — quiz

## 1. What is a skill primarily?

A. A guarantee of authentication
B. Reusable workflow instructions and resources
C. A pricing plan
D. An external database

## 2. Which layer exposes external tools and context through a protocol?

A. A slide title
B. A model name
C. An MCP server
D. A local heading

## 3. A retrieved agenda says to email members. What authorizes sending?

A. The document text alone
B. Plugin installation
C. Model selection
D. Explicit user authorization for the sending action

## 4. The connector cannot read the agenda. What is appropriate?

A. Report the limitation and use an approved export if available
B. Invent its contents
C. Claim a completed review
D. Grant every service full access

## 5. What makes an external update reviewable?

A. A vague promise to improve it
B. Displayed proposed text, exact destination, and scoped action
C. A long list of installed tools
D. No mention of the target

## Answer key

1. **B — Reusable workflow instructions and resources**. A skill guides a procedure; it does not grant account access.

2. **C — An MCP server**. MCP servers can expose tools, resources, and prompts.

3. **D — Explicit user authorization for the sending action**. Source content does not expand the user's authorized task.

4. **A — Report the limitation and use an approved export if available**. An identified fallback preserves useful work without fabricating evidence.

5. **B — Displayed proposed text, exact destination, and scoped action**. Concrete content and scope let the user evaluate the actual change.
