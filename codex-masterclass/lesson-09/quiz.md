# Lesson 09: Long-running work, delegation, and scheduled checks — quiz

## 1. What makes a long-running goal useful?

A. An endless instruction to improve
B. A measurable outcome with constraints and verification
C. Maximum worker count
D. No stopping condition

## 2. Who reconciles conflicting worker outputs?

A. Nobody if both finished
B. The first worker automatically
C. The parent responsible for integration
D. The scheduling clock

## 3. A local scheduled check needs files on your computer. What matters?

A. Only the model name
B. Only the prompt length
C. Only a web browser login
D. The local computer, app, project, and required access must be available

## 4. The monitored source cannot be read. What is correct?

A. Report access failure
B. Report everything healthy
C. Invent the current state
D. Suppress the failure as unchanged

## 5. Which habit supports usage discipline?

A. Poll every source each minute
B. Delegate selectively and match cadence to change
C. Always choose maximum effort
D. Reread the entire project each run

## Answer key

1. **B — A measurable outcome with constraints and verification**. Completion criteria let the agent decide what remains and when to stop.

2. **C — The parent responsible for integration**. Independent outputs still need a coherent combined result.

3. **D — The local computer, app, project, and required access must be available**. Future execution depends on the actual runtime and accessible inputs.

4. **A — Report access failure**. Missing evidence differs from an unchanged healthy state.

5. **B — Delegate selectively and match cadence to change**. Scope, appropriate effort, and cadence reduce unnecessary work.
