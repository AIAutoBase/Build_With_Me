# Lesson 01 prompt templates

## 1. First welcome draft

Draft a 90–120-word welcome for fictional Northstar Workshops. Audience: first-time workshop creators. Facts: planning Tuesday; introduce yourself; draft one workshop idea. Invent no time, price, link, or guarantee. Return the draft, word count, and factual checks. Do not publish.

## 2. Focused factual correction

Revise the draft: remove the invented meeting time and outcome guarantee. Keep only supported facts. Preserve the requested length and member actions. Recheck the full message and list any remaining missing information.

## 3. Acceptance review

Compare this Northstar welcome draft with the supplied synthetic brief. Check 90–120 words, Tuesday planning, introduction, and one workshop idea. Flag unsupported times, prices, links, or guarantees. Return requirement, evidence, and pass/fail for each check.
