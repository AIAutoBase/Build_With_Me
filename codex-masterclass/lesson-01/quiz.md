# Lesson 01: Getting started: model selection and your first verified output — quiz

## 1. Astra is absent from your model choices. What should you do?

A. Assume your installation is broken
B. Use an available model and record the difference
C. Grant broader file permissions
D. Claim you used Astra anyway

## 2. What does selecting a stronger model establish?

A. Permission to publish
B. Access to every local file
C. Which model handles the task
D. A connected Skool account

## 3. The brief says Tuesday but gives no time. Which draft is supported?

A. Join Tuesday at seven
B. Join Tuesday evening
C. Join tomorrow at noon
D. Our planning session is Tuesday

## 4. What is the strongest acceptance evidence for a word limit?

A. Counting the actual draft
B. The agent says it is concise
C. The prose sounds polished
D. The selected reasoning effort is high

## 5. What is the best correction for an invented guarantee?

A. Make it exciting
B. Remove the guarantee and recheck supported claims
C. Choose a longer format
D. Publish and fix later

## Answer key

1. **B — Use an available model and record the difference**. Model availability varies. You can practice the workflow honestly with an available model.

2. **C — Which model handles the task**. Model selection is separate from tools, connections, and action permissions.

3. **D — Our planning session is Tuesday**. Only the day is supplied. Adding a time or time of day invents information.

4. **A — Counting the actual draft**. The requirement concerns the actual text and must be checked against it.

5. **B — Remove the guarantee and recheck supported claims**. A focused correction names the unsupported claim and repeats the relevant check.
