# blackcatmom - social accounts (teach only)

**Nothing in this file gets created on camera.** It is instructions and prompts. Say so in class.

## Before you start (all platforms)

- **Use a dedicated email** for the brand, for example a new mailbox like `hello@blackcatmom.com` or a new Gmail. Do not use your personal email.
- **Turn on 2FA** on every account the same day you create it. Use an authenticator app, not only SMS. Save the backup codes in your password manager.
- **Same handle everywhere** if you can. Try `blackcatmom` first. Backups: `blackcatmomhq`, `theblackcatmom`, `blackcat.mom` (where dots are allowed).
- **One profile image for all**: square, 1080x1080 JPG or PNG, the cat mark centered with space around it (most platforms crop it to a circle).
- **Link in bio**: `https://blackcatmom.com` (once it is live; staging links should not go in a bio).
- **Platforms change their screens often.** The menu names below are what they were recently. If a menu has moved, search the platform's help center for the step name.
- **Affiliate disclosure**: when a post has an affiliate link or a gifted product, label it. Use `#ad` or "affiliate link" at the start of the caption, and the platform's own "paid partnership" or branded content label when it applies. Follow each platform's rules. Never hide the disclosure in a pile of hashtags.
- Amazon affiliate links: check the current Amazon Associates rules for social posts before you share them. Some placements are not allowed (see `05-AFFILIATE-NOTES.md`).

## 1. Instagram (professional account: Creator or Business)

**You need:** brand email or phone, the profile image.

**Steps**
1. Install Instagram, choose "Create new account". Use the brand email.
2. Pick the handle and display name. Upload the profile image.
3. Go to your profile, open the menu, then **Settings > Account type and tools > Switch to professional account**.
4. Pick a category (for example "Pet" or "Blogger"). Choose **Creator** (simpler for a personal brand) or **Business** (needed for some shop and ad tools).
5. Edit profile: bio, link, and turn on 2FA under **Accounts Center > Password and security**.

**Sizes:** profile 1080x1080 upload (shown as a small circle). Posts 1080x1350 (4:5). Reels and stories 1080x1920 (9:16).

**Prompt (bio + first 5 posts)**
```
Write an Instagram bio (max 150 characters) for "Black Cat Mom", a page for people who love black cats. Tone: warm, a little witty, elegant, not spooky. Include a call to visit blackcatmom.com. Then write 5 first posts. For each: the photo or reel idea (black cats only, no people's faces), a caption under 120 words, and 5-8 relevant hashtags. Mix: 2 fun facts, 1 folklore post clearly labeled as folklore, 1 care tip that ends with "ask your vet", 1 community question. No medical claims. No income claims. If a post mentions a product link, start the caption with "#ad".
```

## 2. TikTok (Business or Creator account)

**You need:** brand email or phone, the profile image.

**Steps**
1. Install TikTok, sign up with the brand email.
2. Set username and name, upload the profile image.
3. **Profile > menu > Settings and privacy > Account > Switch to Business Account** (or keep a personal/creator account). Note: business accounts have a smaller music library (commercial sounds only).
4. Add bio and website link (the link field may need a minimum follower count on some accounts; check yours).
5. Turn on 2-step verification under **Security**.

**Sizes:** profile 1080x1080 upload. Videos 1080x1920 (9:16).

**Prompt**
```
Write a TikTok bio (max 80 characters) for "Black Cat Mom", a black cat appreciation account. Then plan 5 first videos, each 10-30 seconds: a hook line for the first 2 seconds, a shot list (black cats only, no people's faces), on-screen text, and a caption with 3-5 hashtags. Mix fun facts, one labeled folklore video, one "ask your vet" care tip, and one playful toy video. If a video features an affiliate product, the caption starts with "#ad" and I will turn on the platform's content disclosure setting.
```

## 3. Facebook Page

**You need:** a personal Facebook profile (Pages are created from one; the Page does not show your personal name publicly by default).

**Steps**
1. Log in to Facebook. Open **Menu > Pages > Create new Page** (on some accounts: **Profile switcher > Create a Page**).
2. Page name "Black Cat Mom", category "Pet" or "Personal blog", short bio.
3. Add the profile image and a cover image.
4. Set the username (@blackcatmom) under the Page's settings.
5. Add the website and the brand email as contact.
6. Make sure 2FA is on for the personal profile that controls the Page (**Accounts Center > Password and security**).

**Sizes:** profile 1080x1080 upload. Cover about 1640x624 (keep text centered; phones crop the sides).

**Prompt**
```
Write a Facebook Page "About" description (max 255 characters) and a longer intro (max 100 words) for "Black Cat Mom", a page for black cat lovers with fun facts, folklore (labeled as folklore), care tips that point to your vet, and toy and gear picks. Then write 5 first Facebook posts, each with a photo idea (black cats only), a caption under 80 words, and a question to invite comments. Any post with an affiliate link starts with "#ad" or "Affiliate link:".
```

## 4. YouTube channel (as a Brand Account)

**You need:** a Google account. A Brand Account lets the channel have its own name and lets you add managers later without sharing your password.

**Steps**
1. Sign in to YouTube. Go to **Settings > Add or manage your channel(s) > Create a channel** (wording varies).
2. Choose the option to use a custom name: "Black Cat Mom". This creates a Brand Account.
3. Set the handle (@blackcatmom if available).
4. **Customize channel**: profile picture, banner, description, link to blackcatmom.com, brand email for business inquiries.
5. 2-Step Verification is on the Google account: **myaccount.google.com > Security**.

**Sizes:** profile 800x800. Banner 2560x1440 (keep text inside the center 1546x423 safe area). Shorts 1080x1920.

**Prompt**
```
Write a YouTube channel description (max 1000 characters, first 150 characters must stand alone) for "Black Cat Mom", a channel about black cats: fun facts, labeled folklore, play and toy ideas, and care tips that tell viewers to ask their vet. Then plan 5 first videos: 3 Shorts (under 60 seconds) and 2 longer videos (5-8 minutes). For each: title under 60 characters, a hook line, an outline, and a description that includes "As an Amazon Associate I earn from qualifying purchases." if it links products. No medical claims, no income claims.
```

## 5. Pinterest Business (strong fit for this niche)

Pinterest is a search engine for ideas. Pet, cozy home and gift pins live a long time. It suits this site well.

**You need:** brand email, profile image, the live website (to claim it later).

**Steps**
1. Go to **business.pinterest.com** and choose to create a business account (or convert a personal account under **Settings > Account management > Convert to business account**).
2. Name "Black Cat Mom", username, profile image, short bio.
3. **Claim your website** later, once blackcatmom.com is live: Pinterest gives you a meta tag to add to `index.html` (ask Claude Code to add it). Do not claim a staging URL.
4. Create 4 boards: "Black cat fun facts", "Black cat toys and play", "Cozy cat home", "Black cat care (ask your vet)".
5. Turn on 2-factor authentication under **Settings > Security**.

**Sizes:** profile 1080x1080 upload. Pins 1000x1500 (2:3).

**Prompt**
```
Write a Pinterest business profile bio (max 500 characters, keyword-rich but natural) for "Black Cat Mom". Then write 4 board names with 1-2 sentence descriptions, and 5 first pins: pin title (max 100 characters), description (max 300 characters, natural keywords like "black cat", "cat toys", "cat care"), image idea (2:3, black cats only, text overlay suggestion), and the destination section on blackcatmom.com (#facts, #shop, #community). Pins that link to affiliate products include "#ad" or "affiliate link" in the description.
```

## 6. Threads

**You need:** right now Threads signs up through an Instagram account in most cases. Create the Instagram account first.

**Steps**
1. Install Threads, choose to log in with the blackcatmom Instagram account.
2. Import the profile (name, bio, photo) or edit it.
3. Choose public profile.
4. 2FA is managed in **Accounts Center**, same as Instagram.

**Sizes:** uses the Instagram profile image. Posts: square or 4:5 images work well.

**Prompt**
```
Write a Threads bio (max 150 characters) for "Black Cat Mom". Then write 5 short first Threads posts (max 500 characters each, most under 200): conversational, warm, a little witty. Include one black cat fun fact, one folklore post labeled as folklore, one question to the community, one "what's your cat's name?" style prompt, and one gentle care tip ending with "ask your vet". No hashtag stuffing (0-1 per post).
```

**Prompt**

## 2-week content calendar prompt

```
Create a 2-week content calendar (14 days) for "Black Cat Mom", a black cat appreciation brand with a website (blackcatmom.com: fun facts, toys, food and care shop sections with Amazon affiliate links, and a community email list coming soon).

Platforms: Instagram, TikTok, Facebook Page, YouTube Shorts, Pinterest, Threads, X.

Rules:
- Output a table: Day, Platform, Format (post, reel, short, pin, thread), Topic, Hook or title, Caption draft (short), Call to action, Disclosure needed (yes/no).
- One core idea per day, adapted per platform. Not every platform every day: Pinterest and Instagram daily, TikTok and Shorts 4 times a week, Facebook, Threads and X 3-5 times a week.
- Mix: 40% fun facts and labeled folklore, 25% play and toys, 15% care tips (always "ask your vet"), 20% community (questions, "show us your black cat").
- If today's date range includes October 27 (National Black Cat Day, UK) or August 17 (Black Cat Appreciation Day, US), plan a post for it.
- Any post with an affiliate link: "Disclosure needed: yes", caption starts with "#ad", and the platform's paid or branded content label is turned on where it applies.
- No medical claims. No income or earnings claims. No made-up statistics.
- Black cats only in visuals, no people's faces.
```
