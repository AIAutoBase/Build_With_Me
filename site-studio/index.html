The Mouth

Drop a file in. The brain can read it forever. Class 3 gave the brain a memory you type into. The Mouth lets it read the files you drop on it.

  • Original bytes go to MinIO, self-hosted, on a named volume. A .md copy goes to Postgres.
  • Conversion is a queue in n8n: pending, converting, then converted, failed or unsupported.
  • OCR ships flagged, with a confidence mark next to every result.
  • Four zones in one zone column: personal, business, clients, general. Search always names its zones.
Honest statusDesigned and packed, not run on a live box. The pack is built and checksummed and the zone checker passes offline. Nothing has been ingested on a live box. No conversion has been timed. Files are not scanned for malware.

Site Studio

A small web app. Type a theme, a niche and a description. Every other field has an AI suggest button, plus one that fills everything. Generate site writes a one-page website you can open, download and hand to a client.

  1. Pitch a local business. Rebuild the site of a shop near you and show them before you ask.
  2. Improve your own site.
  3. Start one from zero.

Images: a free Gemini API key inside the app, or the prompts pasted into the Gemini app. Hero video: the app finds a free clip on Pexels with your own free Pexels API key. Create it before class at pexels.com/api (Get started, short form, copy it from "Your API key"). Or use Veo in the Gemini app if your plan has it (check yours).
