Class 9: we built and shipped a site, live.

The brain perceives, remembers, reasons, decides. Today The Mouth is explained, not installed. Its pack is built and checksummed, and it has never been run against a live box.

The gap

Class 3 gave the brain a memory you type into. Ten weeks later it still cannot read a PDF you drop on it.

What The Mouth does

Drop a file in. The brain can read it forever.

Uploadreturns at once, row is pending
MinIOoriginal bytes, self-hosted, named volume
n8n queueconverts in the background
Postgresa .md copy the AI can read
pending → converting → converted | failed | unsupported

The original is the record. The .md is a copy: if it is bad, throw it away and make it again.

Conversion is a queue, not a request. A forty-page PDF must not hold an HTTP connection, and a failed conversion must not look like a failed upload. Audio and video get a row and the status unsupported, with a reason.

OCR

OCR ships, and ships flagged

  • Images and scanned PDFs go through OCR.
  • Every OCR result is stored with a confidence score.
  • The dashboard shows a visible mark next to it.
WhyOCR can fail by writing fluent text with the wrong numbers. Nothing reports an error. The mark is how you know to check.

Four zones, one column

A column, not four folders

personal
business
clients
general
  • One zone column. A file in two folders has two rules, and nothing says which wins.
  • Search always names its zones. There is no "search everything".

Moving a file between zones is one UPDATE, so every move is logged.

Honest status

Designed and packed, not run on a live box

DoneThe pack is built and checksummed. The zone checker passes offline.
Not doneNothing has been ingested on a live box. No conversion has been timed. No malware scan: files from clients are not scanned.

Build live · 25 min

Site Studio

A small web app. Type a theme, a niche and a description. The AI fills the rest. Generate a one-page site you can open, download and hand to a client.

4

Every other field has an AI suggest button: name, audience, sections, colors, tone, call to action, image prompts, video prompts, affiliate categories, social handles. One more button fills everything that is still empty.

Three ways to use it

Pitch. Improve. Start from zero.

  1. Pitch a local business. Rebuild the site of a shop near you and show them before you ask.
  2. Improve your own site.
  3. Start one from zero. Theme, niche, description, and go.
