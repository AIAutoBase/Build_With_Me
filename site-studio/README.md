# Site Studio — Class 10, live format

Type a theme, a niche and a description. The AI fills every other field and writes a one-page website you can open, download and hand to a client. Built live with Claude Code in Class 10 of AI Automations by Hector, 14 October 2026.

Needs Node 20+, Claude Code, a free Gemini API key and, for the hero video, a free Pexels API key.

Honest limits: the free Gemini key no longer makes images (the app falls back to Pollinations, Pexels photos or a prompt you paste into ChatGPT or Gemini). Amazon links use `YOURTAG-20`: put your own Associates tag in. The Mouth, the class this hour explained, has its own page in [`class-10/`](../class-10/).
