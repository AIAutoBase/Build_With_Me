The parts only you can do

The Brain That Runs a Company · Class 3 addendum — the eyes, the door, and the inbox

The container is built and running. What is left happens in the n8n editor and in a browser, so the script cannot do it — it can only wait.

Most of this addendum is this page. Four workflows have to be imported and switched on by hand, and no amount of scripting gets around that.

Before you start: the main Class 3 pack has to be working. If SELECT * FROM kb_sources; does not list your documents, stop and fix that first. A nicer door onto a broken pipeline is still broken.

01

Import all four workflows, then activate all four

Saving is not activating. An inactive workflow answers 404, and the upload will tell you the webhook is missing.

In n8n: Workflows → Import from File. All four are in the addendum's demo/ folder.

FileWhat it is
02-dashboard-api.jsonthe Inbox tab's data
03-email-sort.jsonreads your mail and files it
07-kb-upload.jsonthe drag-and-drop door
08-kb-library.jsonthe document list, and forgetting one
Open n8n workflows http://localhost:5678/home/workflows
Then re-select the credential in every node that has one. n8n gives credentials their own IDs on your machine, and the ones written in these files are mine. A node with a credential it cannot find shows a small warning, then fails at run time with an authentication error that has nothing to do with your key. Open each Postgres and HTTP node, pick your credential from the dropdown, save.

02

Point the dashboard at your n8n

One line in one file. Usually there is nothing to change — but if you get it wrong it costs an hour.

Open dashboard/config.js. It holds one line:

window.BRAIN_N8N = "http://localhost:5678";

Browsing from the same machine the stack runs on? Leave it alone. You are done with this step.

Browsing from a laptop to a stack on another box? Put that box's address there instead — http://192.168.1.50:5678, or whatever yours is.

localhost means the machine the browser is on. Not the machine n8n is on. Point a laptop at localhost and it looks at the laptop, finds nothing, and shows a connection error while n8n is perfectly healthy somewhere else. That one costs people an hour.

03

Connect a mailbox — optional

Only needed for the Inbox tab. Skip it and everything else still works; the Inbox tab just stays empty, which is correct, not broken.

03 — Email sort reads a real mailbox, so it needs a real credential. In n8n: Credentials → New → IMAP.

Open n8n credentials http://localhost:5678/home/credentials
FieldWhat to type
NameDemo Mailbox — use that name and the workflow finds it without editing
Hostyour mail server, usually mail.yourdomain.com
Port993
Userthe full email address
Passwordthe mailbox password, or an app password
SSL/TLSon
Use a mailbox you do not mind seeing on your own screen. A spare address, or one you make for this. The workflow marks mail as read as it processes it — that is how it avoids doing the same message twice. Point it at your main inbox and it will march through everything unread in there.

04

Open it, and drop a document on it

This is the proof. Everything before it was setup.

Three tabs: Inbox, Ask, Documents. Go to Documents and drag a PDF onto the drop zone. It should appear in the list within a few seconds, with a chunk count.

Open the dashboard http://localhost:8088 · if you changed the port, use yours

Then check the page and the database agree with each other:

docker compose exec -T postgres psql -U brain -d brain -c 'SELECT * FROM kb_sources;'

If they disagree, the page is showing you something stale and the query is right.

A scanned PDF will be refused, and that is the system working. A scan is a photograph of a page. There is no text in it to extract, so the upload comes back grey with "nothing to read" and does not go into the memory. If it went in, you would have a document that appears to be filed and answers nothing — and you would only find out the day you needed it.

If something here will not work

What you seeWhat it means
Page loads, tabs empty, red box n8n is not reachable. Check config.js, then check the workflow is Active.
Could not load inbox.html bi-brain-web is not running. docker compose ps.
Upload says the webhook answered 404 07 — KB upload is not Active. Saving is not activating.
Upload says it could not reach n8n config.js is pointing somewhere wrong. Step 2.
Everything green, list is empty The Postgres credential is on the n8n database instead of brain.
Dashboard fine, Inbox tab empty No mail sorted yet. Is 03 — Email sort Active, and is there unread mail?

The browser console is not optional here. Right-click, Inspect, Console. A page that looks blank and a page that is failing look identical from the outside, and the console is the difference.
