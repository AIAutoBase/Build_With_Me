The script must obey these rules:

1. Safe to run twice. Check whether something is already done before doing it again.
   Never overwrite ~/brain/.env — that file holds the key that decrypts my saved n8n
   credentials, and replacing it silently locks me out of every credential I have saved.

2. Fail loudly. Bash: set -euo pipefail. PowerShell: $ErrorActionPreference = 'Stop'.

3. Phases and gates. After each block of [AUTO] commands, print a numbered
   "DO THIS YOURSELF" block covering the [HUMAN] steps that come next, then exit 0
   printing the exact command to run to carry on. When I re-run it, it must skip the
   work that is already finished and pick up where it stopped.

3b. At every gate, OPEN setup-gate.html in my browser rather than only printing a list
   at me. It is the same steps with clickable buttons, the exact values to type, and the
   prompt to paste back to you. Use the right command for my machine:

     Linux            xdg-open setup-gate.html
     Mac              open setup-gate.html
     WSL (Windows)    explorer.exe "$(wslpath -w setup-gate.html)"
     PowerShell       Start-Process setup-gate.html

   Two things about this that will bite you:

   - explorer.exe returns a non-zero exit code even when it worked. Under
     set -euo pipefail that kills the script on a step that actually succeeded. Append
     `|| true` to it.
   - If nothing opens — a headless box, a server over SSH, no browser installed — do
     not fail. Print the full path to the file and the steps in the terminal instead,
     and carry on. Opening a browser is a convenience, never a requirement.

   At the OpenRouter gate specifically, ALSO open the credits page directly, in the same
   way: https://openrouter.ai/settings/credits — that is the page where I put money on
   the account, and it is the step people skip. Open it from the shell, not from
   JavaScript inside the page: a second tab opened by a script in the page gets eaten by
   the popup blocker.

   or FAIL for each:

     - /healthz returns 200 (the root address returning 404 is normal, do not treat

     - psql \d kb and \df cosine_sim kb_search
     - the cosine_sim sanity check returns 1 | 0 | -1
     - SELECT * FROM kb_sources; returns four sources
     - array_length(embedding,1) is 1536
     - both curl webhook tests behave as the README says
   A FAIL stops the script with a plain-English explanation. Never print PASS for a
   check you did not run.

5. Do not reimplement install.sh. The pack ships it and it is already safe to run
